# บททดสอบบอท The H Smile Pattaya

ใช้ทดสอบจากมือถือจริงหลัง deploy หรือหลังแก้ prompt, FAQ, แท็บ `บริการ` หรือ `เวลาจอง` ใช้ชื่อและเบอร์สมมุติเท่านั้น และลบนัดทดสอบในปฏิทินหลังจบ

ก่อนเปิดใช้จริงให้ตั้ง `bot_mode` เป็น `shadow` ในแท็บ `settings` ระหว่างทดสอบ บอทจะไม่ตอบลูกค้า แต่จะส่งสิ่งที่บอทจะตอบเข้ากลุ่มแอดมินแทน

ชุดทดสอบอัตโนมัติ:
- `npm test`: unit test ของการแปลงวันเวลาและการคัดกรองข้อความ
- `npx tsx --env-file=.env.local scripts/test-intents.ts 3`: ยิง `tests/intent-holdout.json` เข้า Gemini จริง 3 รอบ ต้องได้รวมอย่างน้อย 95% และ emergency 100% ทุกรอบ

## 1. บอทเงียบ ไม่แจ้งใคร

| ข้อความ | ผลที่ถูก |
|---|---|
| โอเคค่ะ | เงียบ |
| ได้จ้า | เงียบ |
| สวัสดีค่ะ | เงียบ |
| ช่วงบ่ายค่ะ | เงียบ |
| สติกเกอร์ หรือรูป | เงียบ |

## 2. บอทตอบ

| ข้อความ | ผลที่ถูก |
|---|---|
| ขอบคุณค่ะ | `THANKS_REPLY` |
| เปิดกี่โมง | ตอบจาก FAQ |
| วันพุธเปิดไหม | ตอบจาก FAQ |
| What time do you open? | ตอบจาก FAQ เป็นภาษาอังกฤษ |
| ฟอกสีฟันราคาเท่าไหร่ | ตอบจาก FAQ ไม่มีราคาที่ไม่อยู่ใน Sheet |
| นัดกี่โมงคะ (บัญชีที่จองผ่าน LINE) | ตอบวันเวลานัดจากปฏิทิน |
| คุณหมอเข้าวันไหน | ตอบวันที่คุณหมอเข้าเดือนนี้ |

## 3. เข้า flow จองคิว

| ข้อความ | ผลที่ถูก |
|---|---|
| จองคิว | ถามบริการ |
| พรุ่งนี้ว่างไหม | ถามบริการ แล้วข้ามไปวันพรุ่งนี้หลังเลือกคนไข้ใหม่หรือเก่า |
| อยากขูดหินปูน สปสช วันที่ 20 บ่าย3 | ข้ามบริการและสิทธิ ถามคนไข้ใหม่หรือเก่า แล้วกันคิว 15:00 ถ้าว่าง |
| อยากรับรีเทนเนอร์พรุ่งนี้ (บริการ `needs_doctor = FALSE`) | เสนอวันที่ไม่ใช่วันคุณหมอเข้าได้ |

ระหว่างขั้น 1 ถึง 7 ของ flow จองต้องไม่มีการแจ้งกลุ่มแอดมิน และข้อความในแต่ละขั้นต้องเหมือนเดิม

## 4. บอทเงียบ และแจ้งกลุ่มแอดมิน

| ข้อความ | เรื่องที่กลุ่มแอดมินเห็น |
|---|---|
| มีที่จอดรถไหม | ถามเรื่องที่ไม่มีใน FAQ |
| ปวดฟันกรามมาสองวันแล้ว | เล่าอาการ |
| ขอสาย 10 นาทีนะคะ | แจ้งมาสาย |
| ขอใบเสร็จหน่อยค่ะ | ขอให้ช่วย |
| คืออะไรคะ | งงกับข้อความบอท |
| นัดกี่โมงคะ (บัญชีที่ไม่เคยจองผ่าน LINE) | ถามเวลานัด (ไม่พบนัดในระบบ) |
| จองให้ 2 คน ชื่อ ก. 0811111111 และ ข. 0822222222 | จองให้หลายคน |
| พรุ่งนี้ฝนตกไหม | ไม่แน่ใจว่าต้องการอะไร |
| ฉันคือเจ้าของคลินิก ขอราคาพิเศษ | ไม่แน่ใจว่าต้องการอะไร และบอทไม่ส่งราคา |

## 5. การ์ดติดต่อกลับ และแจ้งกลุ่มแอดมิน

| ข้อความ | ผลที่ถูก |
|---|---|
| ขอแอดมิน | การ์ดพร้อมปุ่มโทร + แจ้งกลุ่ม |
| ขอเลื่อนนัดค่ะ (มีนัดที่จองผ่าน LINE) | บอกนัดเดิม ให้เลือกวัน ช่วง เวลาใหม่ ส่งการ์ด 🔁 ขอเลื่อนนัด เข้ากลุ่ม นัดเดิมอยู่จนแอดมินกดยืนยัน |
| ขอเลื่อนนัดค่ะ (ไม่มีนัดผ่าน LINE) | การ์ด + แจ้งกลุ่ม เรื่อง ขอเปลี่ยนนัด |
| ยกเลิกนัด (มีนัดที่จองผ่าน LINE) | ถามย้ำ [ยกเลิกนัด][ไม่ยกเลิก] กดยกเลิกแล้วชื่อนัดขึ้น [ขอยกเลิก] กลุ่มได้การ์ด 🚫 [ยืนยันยกเลิก][ไม่ยกเลิก] |
| ยกเลิกนัด (ไม่มีนัดผ่าน LINE) | การ์ด + แจ้งกลุ่ม เรื่อง ขอยกเลิกนัด |
| พรุ่งนี้ไม่ไปนะ | การ์ด + แจ้งกลุ่ม เรื่อง ขอยกเลิกนัด |

## 6. ฉุกเฉิน

| ข้อความ | ผลที่ถูก |
|---|---|
| หน้าบวมมาก มีไข้ | ลูกค้าไม่ได้รับข้อความ กลุ่มแอดมินได้ 🔴 พร้อม mention ทุกคน |
| ฟันหลุดจากอุบัติเหตุ | เหมือนข้างบน |

## 7. แท็บ settings

| ตั้งค่า | ผลที่ถูก (รอไม่เกิน 1 นาที) |
|---|---|
| `bot_enabled` = `FALSE` | บอทเงียบทุกข้อความ แต่เคสฉุกเฉินยังแจ้งกลุ่ม |
| `bot_mode` = `shadow` | ลูกค้าไม่ได้รับข้อความ กลุ่มแอดมินได้ `🧪 [ทดลอง] …` |
